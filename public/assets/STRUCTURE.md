# Asset Organization Structure

This folder contains all static assets used in the application. Organized by category for easy maintenance.

## 📂 /public/assets/work/
- **🎥 /videos/**: Video files for Reels and Portfolio.
- **🎨 /creatives/**: Design works, branding identity, and social media kits.
- **🚀 /ads/**
    - **🖼️ /creatives/**: Primary ad campaign images/videos.
    - **📊 /proofs/**: Screenshots of ad metrics and performance validation.
- **💻 /projects/**
    - **🖼️ /covers/**: Thumbnail/cover images for Web Dev, SEO, and Automation projects.

---

### Best Practices:
1. **Naming**: Use kebab-case (e.g., `orgalife-reach-proof.png`) for all files.
2. **Pathing**: Reference these files in code starting with `/assets/...`.
3. **Format**: Use `.webp` or `.jpg` for optimized web performance where possible.
